# Description
This project provides a simplified interface for establishing IPsec VPN connections on Windows using the Win32 API. It compiles into a dynamic-link library (windows_vpn.dll) that can be integrated into other applications to programmatically manage VPN connections.

The project is built using Microsoft Visual Studio.

## Exported Functions

### `int create_profile(char* vpnEntryName, char* vpnServerAddress, char* username, char* password, char* pbkPath);`
Creates a new IPsec VPN profile.  
- `vpnEntryName`: Name of the VPN profile.  
- `vpnServerAddress`: IP or hostname of the VPN server.  
- `username`: VPN username.  
- `password`: VPN password.  
- `pbkPath`: Path to the phonebook file (PBK). This file stores the VPN profile which is generaten by the function. 
---
### `int delete_profile();`
Deletes the existing VPN profile.  
- Not implemented. This function is unneeded on windows and is included only for compatibility with linux VPN interface. Simply delete the pbk file generated by create_profile to remove the profile.
---
### `int connect_vpn(char* profileName, char* pbkPath);`
Establishes a VPN connection.  
- `profileName`: Name of the VPN profile to connect.  
- `pbkPath`: Path to the phonebook file (PBK).
---
### `int disconnect_vpn(char* profileName);`
Disconnects an active VPN connection.  
- `profileName`: Name of the VPN profile to disconnect.
---
### `int status(char* profileName);`
Returns the connection status of the specified VPN profile.  
- `profileName`: Name of the VPN profile.  
- **Return value**: Integer status code:
  - `-1`: Error
  - `0`: Connected
  - `1`: Disconnected
